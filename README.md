# Cinematic Memories — Digital Wedding Invitation

Undangan pernikahan digital bertema film sinematik (35mm aesthetic) yang dibangun menggunakan **Next.js (App Router)**, **Tailwind CSS**, **GSAP**, dan **Lenis**.

## Fitur Utama

- 🎬 **Cinematic Aesthetics**: Film leader 3-2-1 countdown, film grain, light leak, letterbox bar, dan timecode counter.
- 🎵 **Adaptive Film Score**: Musik latar otomatis menggunakan Web Audio API tanpa file audio eksternal.
- 💌 **Personalisasi Tamu**: Parameter URL otomatis (contoh: `?to=Nama+Tamu`).
- 📜 **Smooth Storytelling**: Integrasi GSAP ScrollTrigger & Lenis smooth scroll.
- 📍 **Interactive Maps & RSVP**: Modal venue interaktif, salin nomor rekening instan, dan form RSVP.

## Menjalankan Proyek

```bash
# Install dependencies
npm install

# Jalankan server development
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser Anda.
